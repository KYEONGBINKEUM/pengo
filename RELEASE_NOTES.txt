Pengo 1.0.14

- 결과 자동 보강 (옵션 화면 "자동 보강", 기본 켜짐)
  - 접근성·SEO: 이미지 대체 텍스트(alt), 아이콘 링크 라벨, 본문 바로가기 링크, 메타 설명·Open Graph·Twitter·JSON-LD, 첫 화면 밖 이미지 지연 로딩
  - 반복 요소: 같은 모양이 3개 이상 이어지면 ul/li 로 묶고, 날짜는 time 태그로
  - 폼·게시판: "이름/연락처/문의 내용 입력" 같은 입력칸을 input/textarea 로, "문의하기·신청" 같은 링크를 submit 버튼으로, 번호/제목/작성일 목록을 표 구조(role)로
- 이미지: "자동" 화질 추가(사진은 작게, 그래픽·투명 이미지는 선명하게), 투명한 곳이 없는 이미지는 알파 채널 제거로 용량 축소
- 글꼴: 자주 쓰는 글꼴(나눔·IBM Plex·Poppins 등)을 구글 폰트로 자동 연결, 글꼴 파일이 없는 글꼴은 css/fonts.css 에 @font-face 자리와 fonts/ 폴더 안내를 만듦
- 다른 형식으로도 내보내기: 정적 HTML, React(Vite), Vue(Vite), 워드프레스 테마, 그누보드5 테마 (결과 폴더의 targets/ 안에 만들어짐)
- 프리셋: 옵션 화면 위쪽에서 화질·보강·내보내기 설정을 이름 붙여 저장하고 불러오기
- GitHub 저장소 이름이 pengo 로 바뀜 (이전 주소도 자동으로 연결됨)

1.0.3 변경 사항

- 헤더 GNB 메뉴를 하드코딩하지 않고 inc/nav.php 로 분리합니다
  · inc/top.php : <ul class="gnb"><?php include "nav.php"; ?></ul>
  · inc/nav.php : <li class="gnb_dp1"><div><a href="javascript:GoPage('코드')">메뉴</a></div><? include "s_gnbN.php" ?></li> …
  · inc/s_gnb1.php ~ s_gnbN.php : 하위(2차) 메뉴를 만들 빈 틀 (include 오류 방지)
  · inc/link.php 의 GoPage 에 메뉴 코드별 이동 경로(/doc/코드.php) 자동 추가
- 메뉴 이름과 GoPage 코드는 templates/base/nav-codes.json 에서 관리합니다 (목록에 없는 이름은 menu1, menu2 …)

버그 수정
- 포토샵 줄바꿈(Shift+Enter)이 글자로 남던 문제 수정 (달력 요일·날짜 열이 어긋나던 현상)
- 섹션 배경에 클리핑 레이어가 겹칠 때 질감 배경 대신 흰색이 적용되던 문제 수정
- PSD 글꼴(font-family)을 CSS 로 출력하고 Google Fonts 링크를 head.php 에 추가
- 번호가 붙은 글자 묶음(txt2 등)도 공통 글자 스타일을 받도록 수정
- 좌우 양끝 배치는 gap 큰 값 대신 justify-content:space-between 으로 출력
- 소수점 정리: px 는 정수, line-height 는 소수 1자리, 투명도·자간은 소수 2자리까지
