# Pengo

PSD 파일 하나로 HTML · CSS 코드를 자동으로 만들어 주는 Windows 프로그램입니다.

이 저장소는 **설치 파일 배포용**입니다.

## 설치

1. [Releases](https://github.com/KYEONGBINKEUM/pengo/releases)에서 `PSD-Publisher-Setup-x.y.z.exe` 를 내려받아 실행합니다.
2. 설치가 끝나면 시작 메뉴에서 **Pengo**를 찾을 수 있습니다. (우클릭 → 작업 표시줄에 고정)

> 코드 서명이 없는 파일이라 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. "추가 정보" → "실행"을 누르세요. 파일이 맞는지 확인하려면 함께 올라온 `.sha256` 파일의 값과 비교하면 됩니다.

## 업데이트

프로그램을 켜면 이 저장소의 최신 릴리스를 확인하고, 새 버전이 있으면 화면 왼쪽 위에 알림이 뜹니다. **업데이트** 버튼을 누르면 내려받아 체크섬을 확인한 뒤 자동으로 설치하고 다시 시작합니다. (프로그램이 외부로 보내는 정보는 버전 확인 요청뿐입니다.)

## 요구 사항

- Windows 10 이상 (64비트)
- 변환 결과의 일치율 측정에는 Microsoft Edge 또는 Chrome이 필요합니다.
